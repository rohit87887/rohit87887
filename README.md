## Featured Projects

### TradeChain AI
AI-powered trading journal and portfolio performance analyser with blockchain-verified performance records and smart-contract-style strategy automation. Tracks trades end to end and computes P&L, win rate, profit factor, Sharpe ratio, max drawdown, equity curves and a behavioural scoring model. Frontend-only prototype: blockchain anchoring is simulated, while trade-record hashes are real SHA-256 values computed in the browser.

**Stack:** JavaScript, SHA-256, localStorage
[Repository](https://github.com/rohit87887/tradechain-ai) · [Live demo](https://rohit87887.github.io/tradechain-ai/)

### IndiaBites — Hybrid Restaurant Recommender
An explainable hybrid restaurant recommendation system with personalised fusion weights, built for CSE4077 (Recommender Systems) at VIT Chennai. Combines recommendation strategies and explains why each result was surfaced.

**Stack:** Python, Recommender Systems
[Repository](https://github.com/rohit87887/IndiaBites-Hybrid-Restaurant-Recommender)

### AI-Based Video Fire Detection
FireNet-CNN with image segmentation that analyses video frame by frame, draws live bounding boxes with confidence scores, raises early smoke warnings, classifies each video as FIRE / SMOKE / NO FIRE, and returns a timeline of exactly when fire appears.

**Stack:** Python, TensorFlow, CNN, OpenCV
[Repository](https://github.com/rohit87887/video-fire-detection)

### IAEP-Net — Road Surface Crack Detection
Dual-encoder pavement crack segmentation pipeline (CNN + Swin Transformer) with an adaptive, quality-conditioned image-enhancement front end and automatic crack length, width and severity grading. Benchmarked against five baseline segmentation models.

**Stack:** Python, Deep Learning, Swin Transformer, U-Net
[Repository](https://github.com/rohit87887/tarp-road-crack-detection)

### FinTrace Fraud Monitor
Fraud monitoring platform built on the real PaySim dataset of 6.3M transactions, scoring all 9.07M accounts with rule-based detection logic ported into SQL, backed by DuckDB with account timelines and generated case reports.

**Stack:** Python, DuckDB, SQL, Pandas
[Repository](https://github.com/rohit87887/fintrace-fraud-monitor)

### DCT-Based Blind Image Watermarking
Robust blind watermarking framework using Hessenberg-SVD scrambling for secure colour image authentication. Embeds a scrambled watermark into mid-frequency DCT coefficients; extraction is blind, so the original image is never needed. Purely DCT-based for efficiency, and tested for robustness under noise, sharpening and scaling attacks.

**Stack:** Python, DCT, Hessenberg-SVD, Digital Image Processing
[Repository](https://github.com/rohit87887/DCT-Hessenberg-SVD-Watermark)

### Network-Restricted Decryption
Java encryption system that binds decryption to a specific network environment. Messages are AES-encrypted, the AES key is RSA-wrapped, and a Wi-Fi fingerprint of the network is tied to the payload, so a message can only be decrypted from the intended network context.

**Stack:** Java, AES, RSA, JSON
[Repository](https://github.com/rohit87887/Network-Restricted-Decryption)

### HealthCover Predictor
Web application for health insurance analytics: upload CSV or XLSX datasets, visualise them through interactive dashboards, and run trained ML models for insurance-type classification and cost prediction.

**Stack:** Python, Scikit-learn, Data Visualisation
[Repository](https://github.com/rohit87887/HealthCover-Predictor)
